*   Delphi / RAD Studio (versão X ou superior)
*   *Outros requisitos do seu sistema*

## 🛠️ Como Executar o Projeto

1.  Clone este repositório para sua máquina local.
2.  Abra a IDE do Delphi.
3.  Vá em `File > Open` e selecione o arquivo do projeto (`.dproj`).
4.  Configure as credenciais de banco de dados e outras variáveis de ambiente necessárias.
5.  Compile e execute o projeto (pressionando `F9` ou clicando em Run).
